# Bayu Yoga Astario - Personal Portfolio

Portofolio pribadi resmi **Bayu Yoga Astario**, Fresh Graduate S1 Sistem Informasi dari Universitas Buana Perjuangan Karawang. Website ini mendokumentasikan perjalanan akademik, dedikasi keilmuan, serta pengalaman magang profesional di industri perbankan dan kepanitiaan.

## 🚀 Fitur Website
- **Personal Branding & Hero Section**: Pengenalan profil, ringkasan keahlian, dan tombol download CV.
- **Tentang Saya**: Narasi portofolio pribadi dan sorotan pengalaman magang nyata.
- **Pengalaman Profesional**: Rekam jejak magang (Funding Intern di PT Bank Tabungan Negara (Persero) Tbk) serta kegiatan kepanitiaan/organisasi lengkap dengan sertifikat.
- **Sertifikasi & Keterampilan**: Dokumentasi keahlian teknis dan sertifikasi resmi.
- **Kemampuan Bahasa**: Ringkasan kecakapan Bahasa Indonesia & Bahasa Inggris.
- **Dukungan Multi-bahasa**: Tombol toggle bahasa (ID / EN).
- **Tema Gelap / Terang**: Pilihan mode Dark/Light.
- **Desain Responsif**: Tampilan optimal di desktop, tablet, dan smartphone.
